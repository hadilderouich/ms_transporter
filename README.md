# MSTransport — Web & Mobile Application

A full-stack **web and mobile transportation management platform** developed for **MSTransport**, a French moving and logistics company.

The platform was designed to simplify moving services, improve customer experience, and facilitate the management and tracking of deliveries.

## About the Project

This project was developed as part of my **final-year engineering project and internship** at MSTransport.

The goal was to create a practical digital solution for managing moving and delivery services, particularly the transportation of large household items and goods.

The solution includes both a **web application** and a **mobile application**, providing customers with an easy way to access transportation services and follow their deliveries.

## Main Features

* Moving and transportation services for large household items
* Presentation of available transportation services
* Dedicated features for individual and corporate customers
* Real-time delivery tracking
* Online payment functionality
* Real-time application updates
* Notifications for customers
* Simple and user-friendly interface
* Web and mobile accessibility
